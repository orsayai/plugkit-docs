## 1. Create your account & API key

Sign in to the [PlugKit dashboard](https://plugkit.co/dashboard) with Google,
GitHub, or email + password. Then open **API Keys → New Key** and copy the key —
it looks like `sk_...` and is shown **only once**.

<Note>
  All requests go to `https://api.plugkit.co/v1` and require the header
  `Authorization: Bearer sk_...`. The key scopes every call to your account.
</Note>

## 2. Make your first call

List your profiles to confirm the key works:

<CodeGroup>

```bash cURL
curl https://api.plugkit.co/v1/profiles \
  -H "Authorization: Bearer sk_your_key"
```

```ts TypeScript
const res = await fetch("https://api.plugkit.co/v1/profiles", {
  headers: { Authorization: "Bearer sk_your_key" },
});
const { profiles } = await res.json();
```

```python Python
import requests
r = requests.get(
    "https://api.plugkit.co/v1/profiles",
    headers={"Authorization": "Bearer sk_your_key"},
)
print(r.json())
```

</CodeGroup>

## 3. Create a profile

A profile groups the accounts you connect. Create one and keep its `id`:

```bash
curl -X POST https://api.plugkit.co/v1/profiles \
  -H "Authorization: Bearer sk_your_key" \
  -H "Content-Type: application/json" \
  -d '{ "name": "My brand" }'
```

## 4. Connect an account

Start the OAuth flow to link an account (Instagram shown here):

```bash
curl "https://api.plugkit.co/v1/connect/instagram?profileId=YOUR_PROFILE_ID" \
  -H "Authorization: Bearer sk_your_key"
```

You get back an `authUrl` — open it in a browser, approve, and the account is
created. All six platforms are covered in
[Connecting accounts](/concepts/profiles-and-accounts). You can also do this in two
clicks from the dashboard's **Connections** page.

## 5. Publish

```bash
curl -X POST https://api.plugkit.co/v1/posts \
  -H "Authorization: Bearer sk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "profileId": "YOUR_PROFILE_ID",
    "content": "Hello from PlugKit 👋",
    "accountIds": ["YOUR_ACCOUNT_ID"],
    "mediaUrls": ["https://example.com/photo.jpg"],
    "publishNow": true
  }'
```
