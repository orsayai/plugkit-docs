YouTube is a **video-publishing** integration via Google's YouTube Data API.

## Connect

Google OAuth flow:

```bash
curl "https://api.plugkit.co/v1/connect/youtube?profileId=YOUR_PROFILE_ID" \
  -H "Authorization: Bearer sk_your_key"
```

Open the returned `authUrl`, approve on Google's consent screen, and the channel
is connected after the callback.

## Publish a video

Provide a **public video URL**. YouTube requires a title — pass one explicitly
with `title` (100 characters max); without it, PlugKit falls back to the start
of `content`, which is a stopgap:

```bash
curl -X POST https://api.plugkit.co/v1/posts \
  -H "Authorization: Bearer sk_your_key" -H "Content-Type: application/json" \
  -d '{ "profileId": "PROFILE_ID", "accountIds": ["ACCOUNT_ID"],
        "title": "Episode 1 — how we built it",
        "content": "Full description here…",
        "mediaItems": [{ "type": "video", "url": "https://…/video.mp4" }],
        "privacy": "public", "publishNow": true }'
```

`privacy` accepts `public`, `unlisted` or `private`. YouTube-specific options
(`youtubeTags`, `youtubeCategoryId`, `madeForKids`, `notifySubscribers`,
`aiGenerated`) are listed in [Publishing](/guides/publishing#platform-options).
A `thumbnail` on the video's media item sets a custom thumbnail.

## Analytics

YouTube feeds the [analytics store](/guides/analytics): views, likes and
comments per video, plus subscriber count measured daily. Videos uploaded
outside PlugKit are picked up too.

<Note>
  These are **totals since publication**, not a day-by-day series. Per-day views
  live in the YouTube Analytics API, which requires a separate Google audit — so
  the daily series PlugKit shows is the one it records itself, from the day you
  connect. A channel that hides its subscriber count returns `null`, not `0`.
</Note>

## Comments

YouTube comments show up in the [engagement feed](/guides/engagement): read,
reply, hide and delete. Replying and moderating need the `youtube.force-ssl`
permission; a channel connected before it was offered must reconnect.

## Not supported

Messaging isn't exposed (YouTube has no DMs).

## Permissions

Scopes: `youtube.upload` (publishing), `youtube.readonly` (analytics, reading
comments) and `youtube.force-ssl` (replying to and moderating comments).
