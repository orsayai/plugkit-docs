PlugKit is a single REST API that connects social and messaging accounts through
**official platform APIs** and lets you act on them — publish content, read and
send messages, manage comments, pull analytics — without integrating each
platform yourself. Same request shape everywhere, no per-API quirks.

## Supported platforms

| Platform | Publish | Messaging | Comments | Analytics | How you connect |
| --- | :---: | :---: | :---: | :---: | --- |
| **Instagram** | ✅ | ✅ | ✅ | ✅ | OAuth (Meta) |
| **WhatsApp** | — | ✅ | — | — | Cloud API credentials |
| **TikTok** | ✅ | — | — | — | OAuth (Login Kit) |
| **YouTube** | ✅ | — | — | — | OAuth (Google) |
| **X (Twitter)** | ✅ | — | — | ✅ | OAuth 2.0 (PKCE) |
| **Telegram** | ✅ | ✅ | — | — | Bot token (@BotFather) |

<Note>
  TikTok publishes as `SELF_ONLY` and YouTube as `private` until each app passes
  its platform review — this is a platform rule, not a PlugKit limit.
</Note>

## How it works

<Steps>
  <Step title="Sign in and create a key">
    Sign in to the [dashboard](https://plugkit.co/dashboard) with Google, GitHub,
    or email, then create an API key. Everything you do is scoped to your account.
  </Step>
  <Step title="Create a profile">
    A profile groups the accounts you connect (think of it as a workspace / brand).
  </Step>
  <Step title="Connect an account">
    Send your user through the platform's official OAuth flow (or paste a token
    for Telegram/WhatsApp). PlugKit stores the token and exposes the account.
  </Step>
  <Step title="Act through one API">
    Publish posts, read and reply to messages, manage comments, pull metrics —
    the same shape of request whatever the platform.
  </Step>
</Steps>

## Base URL

```
https://api.plugkit.co/v1
```

Every request is authenticated with a Bearer API key — see
[Authentication](/authentication).
