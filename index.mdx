PlugKit is a single REST API that connects social and messaging accounts through
**official platform APIs** and lets you act on them — publish content, read and
send messages, manage comments, pull analytics — without integrating each
platform yourself. Same request shape everywhere, no per-API quirks.

## How it works

<Steps>
  <Step title="Sign in and create a key">
    Sign in to the [dashboard](https://plugkit.co/dashboard) with Google, GitHub,
    or email, then create an API key. Everything you do is scoped to your account.
  </Step>
  <Step title="Create a profile">
    A profile groups the accounts you connect (a workspace / brand).
  </Step>
  <Step title="Connect an account">
    Send your user through the platform's flow — OAuth, a bot token, or Cloud
    credentials, depending on the platform.
  </Step>
  <Step title="Act through one API">
    Publish, message, moderate comments, pull metrics — the same request shape
    whatever the platform.
  </Step>
</Steps>

## Base URL

```
https://api.plugkit.co/v1
```

Every request is authenticated with a Bearer API key — see
[Authentication](/authentication).
